# Changelog

## 1.1.0

- New printout in two styles: Cards (a card for each person) and Week grid (a column for each week).
- A Printout card in Settings: 5 built-in layouts, and your own saved layouts.
- Options: write-in lines, orientation, cards per row, text size, font, box style, frames and tints, row shading, color by person or black and white, decoration, custom title, daily list place, times, empty sections, and Extra.
- Every row has the same height and ends in the same line, chore or write-in, so the cards side by side line up.
- Each person's printout color can be picked under Owners.
- Fit to one page (on by default): a full month gives up write-in lines, then empty sections, then text size, before it runs onto page 2.
- Export and import include the printout options, saved layouts, and owner colors.

## 1.0.0

First public release.

- Chores repeat every N weeks, months, or years, aligned to any month. Week chores can fall on a set weekday.
- Owners can take turns or share a chore; shared time splits evenly.
- Optional time estimates, seasons, and notes.
- Daily chores print as a list at the top of the sheet.
- A one-page printable sheet, one section per owner, with blank rows for write-ins and seasonal and holiday corner decorations.
- On-screen check-off, a year view of each person's hours, and a chore calendar.
- Printer search (AirPrint, IPP Everywhere, Mopria), or a printer address.
- Auto-print on the 1st of each month.
- Export and import of all chores as a JSON file.
